# AWWS — приложения для Android

[**Скачать последнюю версию APK**](https://github.com/Thyristornp/AWWS-releases/releases/latest) · [APK 0.4.0](https://github.com/Thyristornp/AWWS-releases/releases/download/v0.4.0/AWWS-0.4.0.apk)

AWWS — прототип приложения автомобильных весов: четыре платформы, развесовка, LIVE/HOLD, локальная история измерений и десять оформлений. Для работы с настоящими весами интеграция BLE ещё не завершена; доступен деморежим.

## Установка и обновления

1. Android 8.0 или новее. Скачайте APK и установите его поверх предыдущей версии AWWS, не удаляя приложение.
2. Версию 0.4.0 со встроенным обновлятором нужно установить вручную один раз.
3. Откройте **Настройки → Обновление приложения**. По умолчанию приложение проверяет и загружает обновления по Wi-Fi без лимита трафика, примерно раз в 6 часов с учётом ограничений Android. Есть ручная проверка.
4. Установка запускается кнопкой и подтверждается Android. При первом запуске установщика разрешите установку из AWWS, вернитесь в приложение и повторите нажатие.

Перед установкой сохраните текущий замер: обновление перезапускает приложение. Записанная история и настройки сохраняются.

## Состав релиза

- `AWWS-X.Y.Z.apk` — подписанная сборка приложения.
- `update.json` — номер версии, минимальная версия Android, размер и SHA-256 APK для обновлятора.

[Описание последнего обновления](https://github.com/Thyristornp/AWWS-releases/releases/latest/download/update.json)

В этом репозитории публикуются только установочные файлы и описание канала обновлений. Исходный код хранится отдельно и не публикуется здесь. Тестовые APK не входят в релизы.
